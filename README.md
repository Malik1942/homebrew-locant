# Homebrew tap for Locant

[Locant](https://github.com/Malik1942/locant) is a macOS menu bar tool: point at one element in any app, and your coding agent gets the element, not a screenshot.

```bash
brew install Malik1942/locant/locant
```

That installs the same signed, notarized `Locant.app` as the dmg on the [releases page](https://github.com/Malik1942/locant/releases). Requires macOS 15 or later.

```bash
brew upgrade locant          # a newer release
brew uninstall --zap locant  # remove the app and its settings
```

The cask is generated by `scripts/cask.sh` in the main repository after each release. Issues go to [Malik1942/locant](https://github.com/Malik1942/locant/issues).
